### 2026-09-09 — Claude Code — branch: claude/pen-agentic
- **Claiming:** `lib/pen/*`, `app/pen/*`, `app/api/pen/*`. **New dependency: `motion@13.2.0`** — other agents must `npm install`.
- Built all four features Agustin specced for an "agentic workspace", each verified against his real recordings (his Mercor interview, 63 diarized utterances) rather than fixtures.
- **1 — Jot and Enhance.** Provenance is per BLOCK, not per character: each paragraph is its own borderless textarea, so editing is ordinary controlled state and there is no contenteditable (no selection/paste/IME class of bug). Black = you wrote it, grey = machine, and editing a grey block promotes it to black because correcting a line is an act of ownership. **Enhance appends, never rewrites** — rewriting in place would make the distinction meaningless and lose what was actually typed. Returns an empty expansion when the transcript does not support one. Transcript is editable as an OVERLAY keyed by utterance index so AssemblyAI's original is never destroyed.
- **2 — Cmd+K archive chat.** Two-stage orchestration: a compact index (title/date/type/summary/people) selects which recordings matter, then only those are loaded and the answer must cite them. One-prompt-with-everything works at four recordings and dies at four hundred. Model emits `[n]` markers + a parallel citation list; unmatched markers are dropped rather than left as dead text. History in `pen_archive_chat`.
- **3 — Instant deliverables.** Draft email / memo / tracker from a SINGLE item (action, missed thing, open question), revealed on hover, always visible on touch. Drafts leave marked gaps like `[candidate name]` rather than inventing specifics — confirmed in practice. Emails carry To:/Subject: inside the body so one Copy takes everything. iOS-style bottom sheet, editable before copying.
- **4 — Briefing email.** Compiles summary / missed / actions / still-open into an email-safe HTML template (inline styles, tables, no webfonts) and sends via the existing Resend helper. **Recipient is always the signed-in user** — no client-supplied address, or it becomes an open relay. Added `GET /api/pen/briefing?id=` to preview the exact HTML without sending.
- **Bugs found and fixed while building (all real, all caught by testing rather than review):**
  - The save indicator said "saved" on a failed PATCH. `onPatch` now rethrows and the editor shows **"not saved"** in red. An editor that lies about saving is worse than one with no indicator.
  - `motion` writes its own `transform` for enter animations, which silently clobbered the palette's CSS `translateX(-50%)` and pushed the sheet off-centre. Centring is now flex on a wrapper.
  - `parsed_output` only exists on `messages.parse()`; I had used `messages.create()` with a cast. Switched.
  - Copy relied solely on `navigator.clipboard`, which needs a secure context AND permission and is absent in several in-app browsers. Added the `execCommand` fallback.
  - The email leaked `&RARR;` and `&MIDDOT;` — `esc()` escapes the ampersand in an HTML entity. Labels now use literal Unicode, and a charset meta was added. **Never pass entities through `esc()`.**
  - `briefing_sent_at` was PATCHed by the UI but missing from the route's allowlist, so it silently 400'd. Added with timestamp validation.
